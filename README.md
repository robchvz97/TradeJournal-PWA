# TradeJournal (PWA)

Diario de trading que se instala como app desde el navegador.
Cargas tus operaciones a mano, con foto. Los datos se quedan en el telefono o la computadora, no en GitHub.

## Abrir

https://robchvz97.github.io/TradeJournal-PWA/

Si esa pagina da 404, activa GitHub Pages:
Settings > Pages > Deploy from a branch > main / root > Save.

## Instalar en iPhone

1. Abre la URL en Safari.
2. Compartir > Agregar a pantalla de inicio.

## Instalar en Android

Chrome > menu > Instalar aplicacion.

## Importante

- Exporta de vez en cuando. Si borras los datos del sitio, se pierden los trades.
- No se conecta a MetaTrader. Es carga manual.
